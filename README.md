\# Road Damage Detection using YOLOv5



\## Overview

This project detects road damages (potholes) using YOLOv5 and MATLAB.



\## Features

\- Deep learning-based detection (YOLOv5)

\- ONNX model integration

\- Image processing in MATLAB



\## Files

\- MATLAB scripts for detection

\- Pretrained YOLOv5 ONNX model

\- Sample outputs



\## Applications

\- Smart city infrastructure

\- Road safety monitoring
